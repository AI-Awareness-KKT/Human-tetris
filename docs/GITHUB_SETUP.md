# Publish this one project

1. Create a separate empty GitHub repository named human-tetris.
2. Upload the contents of this project folder, including assets, src, tools, docs and dotfiles. index.html must be at the repository root, rather than inside an extra nested project folder.
3. In repository Settings → Pages choose Deploy from a branch, main, / (root), then Save.
4. After Pages deployment succeeds, open the URL GitHub displays. index.html is the details page; Play Game links to play.html.
5. Replace PROJECT_URL in website/project-card.html with that real URL, copy its thumbnail using a unique filename into your central website, and add the adjusted card to the central projects.html.

The included workflow checks code and generated files. It does not enable Pages or publish automatically. No account credentials are included.
